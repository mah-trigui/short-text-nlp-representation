In Short-Text NLP, Representation Quality Is Won Before Modeling

Text normalization, slang preservation, and vocabulary design for noisy mental health classification

View Repository Explore Method

Overview

This project classifies short free-text statements from Kenyan university students into four mental health categories: Depression, Alcohol, Suicide, and Drugs.

The central modeling issue was not only algorithm choice. The larger risk was that noisy short text would fragment the vocabulary before modeling even began.

Misspellings, slang, abbreviations, and inconsistent surface forms can split the same concept across multiple tokens, weakening TF-IDF and other sparse representations. The pipeline therefore treated normalization as part of representation design rather than routine text cleaning.

Architecture

The Core Idea

In noisy short-text NLP, the model can lose before training starts if the vocabulary is fragmented by spelling variation.

For a sparse model, these can become unrelated terms:

  • depressed
  • depressd
  • deppressed

At the same time, some terms should not be normalized away. Local slang such as bhang, miraa, and muguka carries real semantic signal and should be preserved.

In applied NLP, preprocessing is part of representation design.

Pipeline Design

Unified text processing

Train and test text were combined before preprocessing so token handling and normalization logic stayed consistent across both sets.

UDPipe tokenization

Text was tokenized before feature building, keeping only meaningful tokens and preparing the data for token-level correction.

Hunspell correction

Misspelled terms were checked and corrected to reduce vocabulary fragmentation before TF-IDF construction.

Slang preservation

Domain slang terms were explicitly whitelisted so generic spelling correction would not destroy local meaning.

TF-IDF + LSA

Sparse lexical features were built using sublinear TF-IDF with L2 normalization, then complemented with 4 latent semantic dimensions.

Multi-model ensemble

One-vs-rest GLMNet, XGBoost, Keras, and StarSpace-style representations were averaged to reduce variance on a small dataset.

Selected Code Snippets

1. Preserve domain slang during spelling correction

tokens$is_correct <- hunspell_check(tokens$token)

slang_terms <- c("bhang", "miraa", "muguka", "shisha", "weed", "meth")
tokens$is_correct[tokens$token %in% slang_terms] <- TRUE

2. Apply token correction before reconstruction

tokens$corrected <- ifelse(
    tokens$is_correct | is.na(tokens$suggestion),
    tokens$token,
    tokens$suggestion
)

3. Build TF-IDF with sublinear scaling and bigrams

vocab <- create_vocabulary(it_train, ngram = c(1L, 2L))
vocab <- prune_vocabulary(vocab,
    term_count_min = 2,
    vocab_term_max = 5000
)

tfidf_model <- TfIdf$new(norm = "l2", sublinear_tf = TRUE)

4. Simple probability averaging across model families

preds_list <- list(pred_glm[[cls]], pred_xgb[[cls]])
if (!is.null(pred_keras)) preds_list <- c(preds_list, list(pred_keras[[cls]]))
if (!is.null(pred_rui)) preds_list <- c(preds_list, list(pred_rui[[cls]]))

avg_pred <- Reduce(`+`, preds_list) / length(preds_list)

Why this matters

  • small noisy text datasets are highly sensitive to vocabulary fragmentation
  • normalization can improve signal density before any model is trained
  • generic text cleaning can erase local or domain-specific meaning if applied blindly
  • representation quality often matters as much as algorithm choice in applied NLP

Where this pattern generalizes

  • support ticket classification
  • social media listening
  • student or customer survey text
  • low-resource or slang-heavy NLP tasks

Key Takeaway

Before choosing the model, make sure the vocabulary reflects the concepts rather than the noise.

In noisy short-text NLP, normalization is not just cleaning. It is a representation decision.
